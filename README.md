# hokenchat（試作）

保険代理店の社内向け AI アシスタントの試作です。**AI（ローカルLLM）もデータもこの PC の中だけで動き**、外部の AI サービスは使いません。Mac と Windows に対応し、デスクトップのアイコンから起動します。

> **AI エージェントへ：** セットアップを頼まれたら、まず [SETUP.md](SETUP.md) を読み、その手順に従ってください。

## できること
- **社内チャット**：約款・社内規程を検索し、根拠の条文を原文のまま、文書名・版・条番号つきで表示（AI は判断をしない）
- **公式LINE（任意）**：本物の LINE とつながる 1:1 トークの受信箱。お客さまごとに AI モード（承認済みの定型文で自動案内）と手動モード（担当者が返信）を切り替え
- **登録文書**：PDF（文字のPDF・スキャンした冊子）、テキスト、写真を取り込んで検索の対象にする。同じ文書名なら版を差し替え
- **利用ログ**：日時・結果・参照した条だけを記録（質問の本文は残さない）
- マイナンバー・カード番号・病歴などは、AI に渡す前に自動で止める

## セットアップ（概要）
1. Python 3.10 以上と Ollama を入れる（[SETUP.md](SETUP.md) の手順2）
2. このリポジトリを置いて、`python3 setup.py`（Windows は `py -3 setup.py`）を実行
3. デスクトップの **hokenchat** アイコンをダブルクリック

## 注意
- 試作のデータはすべて架空です。**実在のお客さまの情報は入れないでください**（損保ジャパンへの確認が済むまで）
- 仕様の詳細は [docs/設計書.md](docs/設計書.md)（PDF 版：`docs/設計書.pdf`）
