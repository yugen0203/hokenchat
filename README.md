# hokenchat（試作 第0.2版）

保険代理店の社内向け AI アシスタントの試作です。**AI（ローカルLLM）もデータもこの PC の中だけで動き**、外部の AI サービスは使いません。Mac と Windows に対応し、デスクトップのアイコンから起動します。

> **AI エージェントへ：** セットアップを頼まれたら、まず [SETUP.md](SETUP.md) を読み、その手順に従ってください。

## できること
- **ログイン**：個人ID＋パスワード＋認証アプリ（多要素認証）。ロールは 管理者（生成AI責任者）／募集人／事務員
- **利用目的タグ**：顧客情報を使う前に目的を選ぶと、その目的に必要な項目だけが表示される
- **社内チャット**：約款・社内規程を検索し、根拠の条文を原文のまま、文書名・版・条番号つきで表示（AI は判断をしない）
- **登録文書**：PDF（文字・スキャン）・テキスト・写真を取り込み、**管理者の承認後**に検索の対象にする。新しい版を承認すると古い版は自動で外れる。`data/inbox/` に置いたファイルも自動で取り込む
- **文書保管庫**：申込書控えを暗号化して保管。**自動車3年・火災5年・その他3年**（登録日から）で自動削除。種目変更・リーガルホールドは申請と承認
- **顧客DB**：メモから項目の下書き（入力支援）→ 人が確認して登録
- **郵送**：送付状・封筒（長3縦書き／角2）・宛名ラベルの PDF。作成者とは別の担当者が照合してから発送
- **見積依頼書**：依頼文から下書き → 承認 → J-NET入力票 → J-NET の結果と突合（J-NET への入力は人）
- **タスク**：依頼文からタスク案 → 人が確定。期限超過と朝のサマリー
- **公式LINE（任意）**：1:1 トークの受信箱。AI モード（承認済みの定型文で自動案内）／手動モード（担当者が返信、AI の下書きつき）。画像・PDF は暗号化して保管し、AI には読ませない
- **監査ログ・月次点検**：誰が・いつ・何の目的で・何をしたか（本文は残さない）。改ざんはハッシュチェーンで検出。AI 停止スイッチ
- マイナンバー・カード番号・病歴などは、AI に渡す前に自動で止める

## セットアップ（概要）
1. Python 3.10 以上と Ollama を入れる（[SETUP.md](SETUP.md) の手順2）
2. このリポジトリを置いて、`python3 setup.py`（Windows は `py -3 setup.py`）を実行
3. デスクトップの **hokenchat** アイコンをダブルクリック
4. 最初の画面で**管理者のアカウントを作り**、スマホの認証アプリを登録する（社員は「社員・設定」で追加）

## テスト
- `python tests/test_phase2.py`：フェーズ2の機能の自動テスト（AI モデル不要・一時フォルダで実行）
- `python eval.py`：本物のローカルLLMでの精度チェック（`--quick` はガードだけ）
- `python tests/fake_ollama.py`：AI モデルなしで画面を試すための「にせ Ollama」（精度は意味を持たない）

## 注意
- 試作のデータはすべて架空です。**実在のお客さまの情報は入れないでください**（損保ジャパンへの確認・外部委託申請が済むまで）
- `data/keys/`（暗号鍵）はバックアップに含めないでください。含めると、削除した申込書控えがバックアップから読めてしまいます
- 仕様の詳細は [docs/設計書.md](docs/設計書.md)（PDF 版：`docs/設計書.pdf`）
